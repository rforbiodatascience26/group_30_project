  7. Calculate total reads, CPM and log2(CPM + 1)

    CPM means Counts Per Million. Normalizes raw gene counts by the total number of reads in each sample, making expression values comparable across samples with different sequencing depths.

    log2(cpm+1) :Applies a log transformation to normalized expression values to reduce skewness, lessen the influence of highly expressed genes, and handle zero counts safely.

    counts_aug <- counts_aug |>
  group_by(sample_id) |>
  mutate(
    total_reads = sum(count),
    cpm = count / total_reads * 1e6,
    log_cpm = log2(cpm + 1)
  ) |>
  ungroup()

  16. Fit linear models

    counts_aug_long_nested <- counts_aug_long_nested |>
  mutate(
    model_object = map(
      .x = data,
      .f = ~ lm(
        formula = log_cpm ~ donor + stimulus,
        data = .x
      )
    )
  )

We fit one model for each gene at 4h and another at 24h. The model accounts for baseline differences between donors while testing the effect of the stimulus on gene expression.

  1. Extract model estimates

    counts_aug_long_nested <- counts_aug_long_nested |>

      .x = model_object,
      .f = ~ tidy(
        x = .x,
        conf.int = TRUE,
        conf.level = 0.95

    )
  )

  6. Adjust p-values and identify differentially expressed genes

    P-values were adjusted using the Benjamini-Hochberg method to control the false discovery rate arising from thousands of simultaneous gene-level tests. And genes with q.value < 0.05 and an absolute estimate > 1 were classified as differentially expressed, while all others were considered not significant..

    gene_estimates <- gene_estimates |>
  group_by(time) |>
  mutate(
    q.value = p.adjust(p.value, method = "BH"),
    expression = case_when(
      q.value < 0.05 & estimate > 1 ~ "Upregulated",
      q.value < 0.05 & estimate < -1 ~ "Downregulated",
      TRUE ~ "Not significant"
    )
  ) |>
  ungroup()
