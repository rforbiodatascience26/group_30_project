3a. Normalising and transforming the counts

Convert raw counts into a normalised expression measure that can be used for exploratory analysis.

We use counts per million (CPM), followed by a log2 transformation. Adding 1 prevents taking the logarithm of zero.

counts_log <- counts |>
  mutate(across(
      -gene_id,
      ~ log2((.x / sum(.x)) * 1000000 + 1) #log2tranformation of CPM
    )
  )

3b. Reshaping the expression table

Each sample is currently represented by a separate column. We reshape the table into long format, so that each row represents the expression of one gene in one sample.

counts_long <- counts_log |>
  pivot_longer(
    cols = -gene_id,
    names_to = "sample_id",
    values_to = "expression"
  )

3c. Combining expression values with sample metadata

expression_data <- counts_long |>
  left_join(metadata, by = "sample_id")

Performing BH adjusment:

We need it since we are testing multiple genes separately, some genes will appear statistically significant just by chance, even if there is no real difference between Candida and control. For example, if all genes had no real effect, using a 0.05 threshold across 61,893 tests could produce roughly 3,095 apparently significant results by chance. BH adjustment corrects for this multiple-testing problem. It controls the false discovery rate (FDR): the expected proportion of false positives among the genes we identify as significant. It does not eliminate all false positives, but it makes our conclusions more reliable.

For 4 h data:

results_4h <- results_4h |>
  mutate(
    adjusted_p_value = p.adjust(p_value, method = "BH")
  )

Then, when identifying significant genes, use the adjusted p-value and identify significance as per articles treshold:

results_4h <- results_4h |>
  mutate(
    regulation = case_when(
      adjusted_p_value < 0.05 & log2FC > 1 ~ "Upregulated",
      adjusted_p_value < 0.05 & log2FC < -1 ~ "Downregulated",
      TRUE ~ "Not significant"
    )
  )

Workflow and conclusion:

Workflow:

Select samples – Separate 4-hour and 24-hour Candida and control samples.

Fit linear models – Fit one model per gene, accounting for donor pairing.

Extract results – Obtain log2FC estimates and p-values for each gene.

Correct for multiple testing – Apply Benjamini–Hochberg adjustment.

Classify genes – Identify upregulated, downregulated and non-significant genes using the fold-change and adjusted p-value thresholds.

Visualise results – Create volcano plots to display differential gene expression
